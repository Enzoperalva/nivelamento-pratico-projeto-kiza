# 🚀 Nivelamento — Engenharia de Software

Este repositório documenta meu **nivelamento em Engenharia de Software**, com foco em desenvolver uma base mais sólida para trabalhar com sistemas modernos.

A proposta é estudar os conceitos por meio de **projetos práticos e progressivos**, aumentando gradualmente a complexidade dos problemas enfrentados.

> **Meu objetivo não é aprender tecnologias isoladamente, mas entender os problemas que elas resolvem.**

---

## 🎯 Objetivos

Ao longo desse nivelamento, quero desenvolver a capacidade de:

* Projetar sistemas;
* Tomar decisões arquiteturais;
* Desenvolver aplicações backend;
* Trabalhar com diferentes formas de persistência e comunicação;
* Escrever testes;
* Identificar e investigar falhas;
* Analisar gargalos e problemas de performance;
* Trabalhar com sistemas distribuídos;
* Colocar aplicações em produção;
* Monitorar e operar sistemas;
* Compreender os trade-offs das decisões técnicas.

A ideia é sair do **"sei utilizar a tecnologia"** para o **"entendo por que, quando e como utilizá-la"**.

---

## 💡 Motivação

A motivação para esse nivelamento surgiu da vontade de aprofundar meus conhecimentos além da implementação de funcionalidades.

Não quero aprender uma tecnologia simplesmente porque ela aparece em uma determinada stack ou arquitetura.

Quero entender **o problema primeiro**.

Por exemplo:

* RabbitMQ → processamento assíncrono;
* Kafka → sistemas orientados a eventos;
* Redis → cache e concorrência;
* Kubernetes → aplicações distribuídas;
* Terraform → infraestrutura como código;
* OpenSearch → busca e indexação.

Dessa forma, cada tecnologia passa a fazer sentido dentro de um contexto, em vez de ser apenas mais uma ferramenta que aprendi a utilizar.

## 📈 Evolução

Este repositório também serve como um registro da minha evolução.

A intenção é poder olhar para trás e comparar:

**onde eu estava → o que estudei → o que construí → o que passei a compreender.**

Não quero medir meu progresso apenas pela quantidade de tecnologias estudadas, mas principalmente pela minha capacidade de **entender problemas e tomar decisões técnicas melhores**.

---

## 🧠 Princípio do nivelamento

> **Problema → conceito → tecnologia → implementação → falha → investigação → melhoria.**

O objetivo não é conhecer uma lista de ferramentas.

É desenvolver, progressivamente, a capacidade de **projetar, construir, testar, colocar em produção e operar sistemas de software**.
